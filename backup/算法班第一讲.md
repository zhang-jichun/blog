## 面试流程介绍
* 准备面试时候python语言最有优势
* 原题 + 套路 + 固定的 follow up
* 面试交流的时候可以讲具体的例子
* 面试官提出问题后，首先要理解问题并确认问题的边界，可以向面试官呈现一下对于问题的理解
* 可以用实例向面试官分析，进而规避较大的错误
* 写完之后可以用实例测试，不要就说写完了
* 面试官可能要求讲解代码，建议用一个实例来介绍代码
* 评判性能 + 优化算法

## 面试官眼中的求职者
* for循环不要超过三层
* 面试的代码量约为20-30行
* 598. zombie in matrix 
    * 分支逻辑中，最好采用一些常量，加强可读性
        * public int PEOPLE = 0
        * public int ZOMBIE = 1
        * public int ZOMBIE = 2
        * if grid[i][j] == PEOPLE: 这样可读性高
* 注意下标越界问题
* 注意stack pop时是否为空
* 平时多练习，犯错几率小
* 小错误对于面试来讲不可原谅
* 不好的写码习惯
    * 耦合度高
