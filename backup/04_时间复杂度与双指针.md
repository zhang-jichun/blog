### 算法的四个复杂度
+ 时间复杂度 - 核心考点
+ 空间复杂度 - 次要考点
+ 编程复杂度 - 能让人看懂
+ 思维复杂度 - 能想得出来
---
### 时间复杂度On的算法
+ 双指针
    + 相向双指针
        + reverse 类型
            + 翻转字符串
            + 判断回文串 
        + two sum 类型
            + 两数之和
            + 三数之和
        + partition 类型
            + 快速排序
            + 颜色排序
+ 打擂台
+ 单调栈，单调队列

### two sum 面试追问
+ 如果输入数据一已排序，哪个算法更好？
    + 双指针算法更好，不需要额外空间且时间复杂度为On
+ 如果需要返回所找的两个数在数组中的下标，哪个算法更好？
    + hashmap方法更好，因为双指针算法需要 num 和 index 打包排序
