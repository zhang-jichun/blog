+ www.lintcode.com/problem/464/
+ 快速排序时间复杂度为O(nlogn)
+ 快排退化：每次分区都极度不平衡，pivot 总是当前子数组的最小值或最大值，导致一边 0 个元素、另一边 n-1 个，递归深度变成 n，每层做 O(n) 的工作，总复杂度 O(n²)
+ 在 left <= right 时仍然能进入循环，是为了确保退出循环时left与right彻底分开，使得后续子快排不会占据相同元素
+ ls[left] < pivot 和 ls[right] > piovt
    + 如果加上等于，当 pivot 恰好是数组的最小值时，分区会完全失效，递归范围不缩小，直接死循环
    + 举例 [3, 2, 2] 如果 ls[right] >= pivot，那么 right 会一直走到 -1下标处，导致死循环

``` python
from typing import (
    List,
)

class Solution:
    """
    @param a: an integer array
    @return: nothing
    """
    def sort_integers2(self, a: List[int]):
        # write your code here
        self.quick_sort(a, 0, len(a) - 1)
        return


    def quick_sort(self, ls, start, end):
        if start >= end:
            return

        left, right = start, end
        pivot = ls[(left + right) // 2]
        while left <= right: # 退出循环时 left right 一定错开
            while left <= right and ls[left] < pivot: # pivot 会拦住 left 指针
                left += 1
            while left <= right and ls[right] > pivot: # pivot 会拦住 right 指针
                right -= 1
            if left <= right: 
            # 两个指针一定会在列表内部被拦住，则一定会至少发生一次交换
            # 如果左右指向相同元素再交换，则该元素不再进入排序，后续子排序变短
            # 如果左右指向不同元素再交换，则两个子序列内至少存在一个元素，后续子排序变短
                ls[left], ls[right] = ls[right], ls[left]
                left += 1
                right -= 1

        self.quick_sort(ls, start, right)
        self.quick_sort(ls, left, end)
        return
```
