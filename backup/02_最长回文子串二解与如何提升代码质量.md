## [最长回文子串（动态规划）](https://zhang-jichun.github.io/blog/post/zui-chang-hui-wen-zi-chuan-%EF%BC%88-dong-tai-gui-hua-%EF%BC%89.html)
### 需要注意的点
+ 区间型动态规划
+ 矩阵的创建方法
    + 基本类型X3还是三个基本类型
    + 引用类型X3则变成对相同类型的三次引用（避免）
---

### 面试需要注意的点
+ 不一定要求用最优解解题
+ 好的代码风格很重要
    + bug free
    + 有意义的变量名，空格，空行
    + 使用清楚的简单逻辑
    + 没有冗余代码
    + 边界检测和异常处理
+ 提高 coding quality 的技巧
    + 二元运算符两边加空格，单元运算符不加空格
    + 括号、for、if 之间加空格
    + 空行分割不同的逻辑块
    + 逗号后面加空格
    + 函数名变量名使用1-2单词
    + 一个函数内部不超过3层缩进
    + 多用子函数减少入口函数代码量
    + 多用continue 少用if
    + 一定要对入口函数的参数进行异常检测
    + 访问下标时，确保不越界
    + 访问对象的属性或方法时，确保对象非空
    + 不使用全局变量
### 举个例子
``` python
if 条件1：
    if 条件2：
        一些操作
        一些操作

# 改用continue
if not 条件1：
    continue
if not 条件2：
    continue
一些操作
一些操作        
```
