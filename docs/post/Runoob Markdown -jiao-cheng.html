Markdown 列表

无序列表使用星号(*)、加号(+)或是减号(-)作为列表标记，这些标记后面要添加一个空格，然后再填写内容
建议统一使用减号 -，因为它在视觉上更清晰

  • 第一项
  • 第二项
  • 第三项

有序列表使用数字并加上 . 号来表示

  1. 第一项
  2. 第二项
  3. 第三项

列表混合嵌套只需在子列表中的选项前面添加两个或四个空格即可

  1. 主要任务
    • 子任务A
    • 子任务B
      1. 详细步骤1
      2. 详细步骤2
    • 子任务C
  2. 次要任务
